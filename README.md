# Systemsoft Disc

## How do I install these formulae?

`brew install systemsoft/disc/<formula>`

Or `brew tap systemsoft/disc` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "systemsoft/disc"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
